# Techwel Clone Frontend

Projeto estático em HTML, CSS e JavaScript puros.

## Como abrir

Abra `index.html` no navegador ou use a extensão Live Server do VSCode.

## Estrutura

- `index.html`: página inicial
- `contato.html`: contato
- `solicitacao-servicos.html`: formulário demonstrativo
- `consultar-os.html`: consulta demonstrativa de OS
- `impressoras.html`: catálogo de impressoras
- `suprimentos.html`: catálogo de suprimentos
- `static/css/style.css`: estilos mobile first
- `static/js/main.js`: menu mobile, feedback de formulário e animações sutis
- `static/img/logo-techwel.png`: logo e base da paleta visual
